# Student ID QR Scanner

A real-time QR code scanner developed using Python, OpenCV, and Pyzbar for detecting and decoding student identification QR codes.

## Features

- Real-time webcam scanning
- QR code detection and decoding
- Visual bounding box around detected QR codes
- Audio alert on successful scan
- Structured data extraction
- Student information display

## Technologies Used

- Python
- OpenCV
- Pyzbar
- Winsound

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
